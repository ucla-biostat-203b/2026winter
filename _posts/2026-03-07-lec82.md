## Q&A

* HW3 feedback (thanks to TA Tomoki Okuno!). Median [IQR]: 276 [262, 289] / 300 (max 312)

    Common deductions:

    * Git workflow: Some students did not follow the intended Git workflow (e.g., very few commits on `develop` or working directly on `main` instead of merging `develop → main`).
    
    * Q1.1 – Primary diagnosis selection: The three diagnoses should follow `seq_num` (see [MIMIC documentation](https://mimic.mit.edu/docs/iv/modules/hosp/diagnoses_icd/#seq_num)), but many students instead selected the most frequent diagnoses.
    
    * Q4 – Age distribution interpretation: Missing explanation for the spike near age 91 in the anchor_age distribution.
    
    * Q6 – Handling simultaneous vital measurements: When extracting the first measurement after ICU admission, ties at the same timestamp were not averaged; instead, a single row was selected.
    
    Common bonus elements:
    
    * Q3 – Insightful interpretation of admission patterns or LOS (+bonus): Additional interpretation of admission timing or length-of-stay patterns beyond basic plots.
    
    * Q4 – Correct explanation of age 91: Correctly recognizing that very high ages appear due to de-identification in MIMIC.
    
    * Q8 – Comprehensive cross-domain visualization (up to +10): Systematic visualization across multiple domains (e.g., demographics, labs, vitals, care unit).

## Checklist on your resume

> A data scientist is someone who is better at statistics than any software engineer and better at software engineering than any statistician.  

- [ ] Linux scripting  
- [ ] Git/GitHub (give your GitHub handle)  
- [ ] Container technology: Docker (if you use it)  
- [ ] Data wrangling (Tidyverse)   
- [ ] Data visualization (ggplot2)  
- [ ] Frontend development (Shiny, web app)  
- [ ] Databases: OLAP (DuckDB), Google BigQuery (spend more time self-studying SQL)  
- [ ] Cloud computing (GCP, AWS, Azure, OCI) (if you use it)    
- [ ] High-performance computing (HPC) on cluster (if you use Hoffman2)   
- [ ] Machine learning: logistic+enet, random forest, boosting (xgboost, lightGBM), SVM, neural network  
- [ ] Deep learning with Keras+TensorFlow (PyTorch is more popular in research) (if you use it in final project)  

* **Use** these tools in your daily work: use Git/GitHub for all your homework and research projects, write weekly research report using Quarto/RMarkdown/Jupyter Notebook, give presentation using ggplot2 and Shiny, write blog/tutorial, ...

* Be open to languages. **Python** is a more generic programming language and widely adopted in data science. **Julia** is attractive for high performance scientific computing. **JavaScript** is dominant in web applications. **Scala** is popular for implementing distributed programs. 

* AI policy (from [Mine Çetinkaya-Rundel](https://speakerdeck.com/minecr/leveraging-llms-for-student-feedback-in-introductory-data-science-courses-stats-up-ai)):

    * AI tools for code: You may use, you must explicitly cite. The prompt you use cannot be copied and pasted directly from the assignment; you must create a prompt yourself.
    
    * AI tools for narrative: Unless instructed otherwise, you may not use generative AI to generate a narrative that you then copy-paste verbatim into an assignment or edit and then insert into your assignment.
    
    * AI tools for learning: You’re welcomed to ask AI tools questions that might help your learning and understanding. But don’t believe everything it says.
